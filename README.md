# 🎯 Desafio Quiz - Tecnologias Web

Este projeto é um **quiz interativo** desenvolvido como desafio prático para aplicar conceitos de **HTML**, **CSS** e **JavaScript**.  
O objetivo é testar conhecimentos de forma divertida e dinâmica, utilizando apenas tecnologias front-end.

---

## 🚀 Tecnologias Utilizadas
- **HTML5** → Estrutura das páginas e elementos do quiz  
- **CSS3** → Estilização, layout responsivo e efeitos visuais  
- **JavaScript (ES6+)** → Lógica do quiz, manipulação do DOM e interatividade
